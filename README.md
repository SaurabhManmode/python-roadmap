# Python Roadmap

This repository is for learning Python from the basics. It follows a beginner-friendly syllabus inspired by the GeeksforGeeks Python tutorial:

https://www.geeksforgeeks.org/python/python-programming-language-tutorial/

## Learning Goals

- Understand Python syntax and core programming concepts.
- Practice input, output, variables, operators, and data types.
- Build confidence with control flow, functions, and data structures.
- Learn object-oriented programming, exceptions, files, modules, and databases.
- Explore practical areas like data science and web development.
- Create small projects after each major topic.

## How to Use This Repository

1. Pick one topic from the syllabus.
2. Create examples and notes inside a topic folder.
3. Practice with small programs before moving ahead.
4. Build the project listed at the end of each major section.
5. Revisit older topics regularly through quizzes and coding problems.
